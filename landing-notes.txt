BAGIAN 1
1 keuntungan memisahkan header dan footer menjadi file component tersendiri, dibandingkan menuliskannya langsung berulang-ulang di index.php?
Keuntungan memisahkan header dan footer menjadi file komponen tersendiri adalah kemudahan dalam pemeliharaan kode karena perubahan navigasi cukup dilakukan pada satu file saja. Hal ini membuat struktur file utama lebih bersih dan hanya berfokus pada konten spesifik tanpa harus menulis ulang kode yang sama. Selain itu, cara ini efektif untuk mengurangi risiko kesalahan pengetikan atau ketidaksamaan antarhalaman akibat perubahan manual yang berulang. Pada akhirnya, pengelolaan proyek website menjadi jauh lebih efisien, hemat waktu, dan terstruktur dengan rapi.

2 Perhatikan halaman-halaman admin (Buku, Kategori, Penulis, Pengguna, Profil) pada Bagian 2 — bagian mana pada halaman-halaman tersebut yang mengalami masalah yang sama seperti header/footer sebelum dipisah?
Bagian pada halaman-halaman admin seperti Buku, Kategori, Penulis, Pengguna, dan Profil yang mengalami masalah pengulangan serupa adalah sidebar, navbar atas, serta footer. Ketiga elemen antarmuka tersebut selalu ditulis berulang kali secara identik di dalam setiap file halaman admin yang berbeda. Jika pengembang ingin mengubah struktur menu navigasi atau informasi hak cipta, mereka harus menyuntingnya satu persatu pada setiap file tersebut. Masalah ini dapat diselesaikan dengan memisahkan bagian-bagian tersebut menjadi file komponen tersendiri agar pengelolaan seluruh halaman admin menjadi jauh lebih efisien dan terstruktur.
